# 🤗 Huihui-Qwen 3.8-27B Тестер

Веб-инструмент для тестирования LLM моделей через Hugging Face Inference API

## ✨ Возможности

- 🚀 Тестирование различных LLM моделей онлайн
- ⚡ Потоковый вывод (stream) в реальном времени
- 🔧 Выбор политики провайдера:
  - **:fastest** — самый быстрый провайдер
  - **:cheapest** — самый дешёвый провайдер
  - **:preferred** — ваш порядок из настроек HF
- 💾 История запросов в текущей сессии
- 📊 Статистика (время ответа, количество токенов)
- 🔐 Безопасное хранение токена в памяти браузера

## 📋 Поддерживаемые модели

- OpenAI GPT-OSS-120B
- DeepSeek-R1
- DeepSeek-V3
- Meta Llama 3.3-70B-Instruct
- Qwen 2.5-72B-Instruct
- Mistral Large
- NousResearch Hermes-3-Pro-70B
- Или загрузите свою модель

## 🚀 Быстрый старт

1. Откройте приложение: https://ardinat355-design.github.io/huihui-ai-Huihui-Qwen3.8-27B--/
2. Получите HF токен: https://huggingface.co/settings/tokens/new?ownUserPermissions=inference.serverless.write&tokenType=fineGrained
3. Введите токен в приложение
4. Выберите модель
5. Напишите вопрос
6. Нажмите "Отправить"

## ⚙️ Требования

- Современный браузер (Chrome, Firefox, Safari, Edge)
- Доступ в интернет
- Hugging Face токен

## 📝 Примечания

- Токен не сохраняется на диск — он хранится только в памяти браузера
- При перезагрузке страницы нужно будет ввести токен заново
- Приложение использует официальный API Hugging Face Inference
